# Handoff, 16 November 2026

For picking up on another computer. Public-safe: private material (submission
texts, names, coding, drafts) is not in git. It travels in the private bundle
`ci-private-bundle-2026-11-16.tgz` (made on the iMac Desktop, 67 MB).

## 1. Set up the other computer

1. `git pull`
2. Unpack the private bundle at the repo root: `tar xzf ci-private-bundle-2026-11-16.tgz`
   This restores `docs/internal/` (Dalby submissions, coding, quotes, fact
   sheet), the submissions scripts and coding page (`scripts/submissions/`,
   held out of git by the publication check), the unpublished
   `src/app/submissions/` page and its data, the Dalby
   audit records, and `sheet-ui-submissions-nav.patch` (the Submissions nav
   link; apply with `git apply` only when the page is ready to publish).
3. `git config core.hooksPath .githooks` (arms the pre-commit publication check).

## 2. Underlining submissions (for filming)

    sh scripts/submissions/coding/start.sh

Opens http://localhost:8765. Select text and press U to underline; click an
underline to remove it. Every change saves to
`docs/internal/dalby-submissions/coding.json` as you go, so stopping the server
loses nothing. State at handoff: 13 items worked on, 38 underlines; items 8-10
of the 10-item check sample still to do. Quotes are rebuilt from the underlines
with `python3 scripts/submissions/make_quotes.py`.
